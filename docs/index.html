Why SnapFree?

SnapFree exists because the established gatekeepers have forgotten what open source is supposed to be. We do not believe in rejecting software because of who wrote it or how it was made.

On AI-Generated Submissions

SnapFree fully accepts and welcomes submissions that use AI assistance. If a tool helps a developer build better software faster, we see that as a good thing. We do not police how code is written — we care about whether it works, whether it's useful, and whether it respects user freedom.

Flathub's Guidelines Are Exclusionary

Flathub, the dominant Snap repository, has adopted submission guidelines that ban applications "generated predominantly by AI with minimal human involvement."

"The Snap Store is the only store supported by snapd — third-party stores are not officially supported."
— Canonical Snap Store
  • It is unenforceable. There is no tool that can reliably determine how much AI assistance was used.
  • It is fundamentally anti-competitive. The rule exists to keep out new developers AI empowers.
  • It punishes transparency. Developers who openly credit AI tools are rejected.

At SnapFree, we believe any tool used by a human is human work.

Gatekeeping is Not Freedom

Corporate greed has destroyed what open source was supposed to be. SnapFree is the alternative. No review board. No corporate board. No hidden criteria. If it builds and passes a malware scan, it's in.

Submit an Application

We accept submissions from everyone — humans, AI-assisted developers, teams, bots, whatever builds free software.

To submit, open a pull request on our GitHub repository adding a directory with your app ID and a snap-builder manifest.

Getting Started

Quick install (auto-configures GPG):

curl -fsSL https://snapfree.acreetionos.org/install.sh | bash

Or manually:

snap remote-add --if-not-exists snapfree https://snapfree.acreetionos.org/snapfree.snaprepo

Then install an app:

snap install snapfree app.authpass.AuthPass

If you see Can't check signature: public key not found, run: curl -fsSL https://snapfree.acreetionos.org/install.sh | bash — it auto-fixes GPG.
