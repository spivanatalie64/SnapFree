Why SnapFree?

Canonical's Snap Store is closed-source server-side and centrally controlled. SnapFree is the community alternative — like FlatFree for Flatpaks.

  • Open index — every snap listed in repo/index.json with hash
  • No gatekeeping — if it builds with snapcraft and is free software, it's in
  • AI welcome — any tool used by a human is human work
  • Install without a store: sudo snap install --dangerous *.snap
