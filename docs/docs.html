Getting Started with SnapFree

SnapFree is a community-maintained Snap repository. This documentation will help you get started with using and contributing to SnapFree.

What is Snap?

Snap is a next-generation packaging format for Linux desktop applications. It provides sandboxing, cross-distribution compatibility, and automatic updates. SnapFree provides a repository of Snap applications that are free and open source.

Adding the SnapFree Repository

snap remote-add --if-not-exists snapfree https://snapfree.acreetionos.org/snapfree.snaprepo

Installing Applications

snap install snapfree org.acreetionos.MediaWriter

Running Applications

snap run org.acreetionos.MediaWriter

Listing Available Applications

snap remote-ls snapfree

Updating Applications

snap update

Creating a Snap Manifest

To submit an application to SnapFree, you need a snap-builder manifest. Here is a basic example:

{
  "id": "org.example.App",
  "runtime": "org.gnome.Platform",
  "runtime-version": "46",
  "sdk": "org.gnome.Sdk",
  "command": "myapp",
  "finish-args": [
    "--share=ipc",
    "--socket=x11"
  ],
  "modules": [
    {
      "name": "myapp",
      "buildsystem": "meson",
      "sources": [
        {
          "type": "git",
          "url": "https://github.com/example/myapp.git"
        }
      ]
    }
  ]
}

Place this manifest in a directory named after your app ID (e.g., org.example.App/org.example.App.json) and submit a pull request.
