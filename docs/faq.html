Frequently Asked Questions

Everything you need to know about SnapFree

What is SnapFree?

SnapFree is a community-maintained Snap repository that accepts all free and open source software, regardless of how it was created. We are the alternative to Snap Store's exclusionary policies regarding AI-assisted development.

How is SnapFree different from Snap Store?

Snap Store bans applications "generated predominantly by AI." SnapFree welcomes them. We believe that any tool used by a human is human work, and we do not police how code is written. If it builds, if it's free software — it belongs here.

How do I install apps from SnapFree?

First add the remote: snap remote-add --if-not-exists snapfree https://snapfree.acreetionos.org/snapfree.snaprepo. Then install: snap install snapfree <app-id>.

How do I submit an application?

Open a pull request on our GitHub repository adding a directory with your app ID and a snap-builder manifest. Our CI validates the manifest, builds the app, and runs a malware scan. If it passes, it's in — no human reviewers needed.

Can I submit apps created with AI assistance?

Absolutely. SnapFree fully accepts and welcomes submissions that use AI assistance. We do not believe in rejecting software because of who wrote it or how it was made. All free software is welcome here.

Is SnapFree affiliated with Snap Store or the Snap project?

No. SnapFree is an independent community project. We are not affiliated with Snap Store, the Snap project, or any corporation. We are simply people who believe in free software without gatekeeping.

What license do my apps need to be?

All applications must be free and open source software. We accept any OSI-approved open source license. Proprietary software is not accepted.

Who maintains SnapFree?

SnapFree is maintained by Natalie Cole-Clift Spiva with contributions from the community. We are independent developers who believe in free software for everyone.

SnapFree is not affiliated with Snap Store or the Snap project.
